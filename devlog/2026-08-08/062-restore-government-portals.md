# 정부청사 포탈 위치 복원

- 원 요청: 정부청사 내부 스마트시티·전망대 포탈 위치를 이전 위치로 복원.
- 원인: 두 포탈이 저장 좌표를 허용하는 설정이라 기존 기본 좌표가 덮어써질 수 있었음.
- 변경 파일: `react-app/src/game/renderers/VillageMapRenderer.ts`
- 변경 내용: 스마트시티 `(1200,1190)`, 전망대 `(1680,1010)`을 유지하고 두 포탈을 고정 위치로 변경.
- 확인: React/Vite 빌드와 WIZ 프로젝트 빌드 후 운영 청크에서 고정 포탈 설정 확인.
