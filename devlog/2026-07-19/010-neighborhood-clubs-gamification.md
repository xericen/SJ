# 동네 동아리 탐색 및 활동 게임화

- **ID**: 010
- **날짜**: 2026-07-19
- **유형**: 기능 추가

## 작업 요약

생활권별 지도에 동아리 건물과 오늘의 이벤트 마커를 배치하고, 활성 인원과 인기 여부를 건물 크기·사람 무리·펄스 효과로 표현했습니다.
사이드바 동아리 추천, 상세 화면, 가입, 회원 배지, 그룹 연결 효과, 활동 체크인, 레벨·배지, 일정과 모집 게시판까지 하나의 탐색 흐름으로 구현했습니다.

## 원문 요청사항

```text
1. 지도 위에 "동아리 건물" 배치

첫마을 광장, 금강 산책길처럼 지도에 있는 랜드마크 아이콘 옆에 동아리 전용 건물(예: "독서 모임 아지트", "러닝 크루 집결지")을 추가
클릭하면 해당 동아리 상세 페이지로 이동 → 지도 탐색하다가 우연히 동아리를 발견하는 재미
인기 동아리는 건물 크기가 커지거나 사람이 많이 모여있는 비주얼로 표현 (활성도 시각화)

2. 사이드바에 "동네 동아리" 섹션 추가
현재 "가까운 이웃" 섹션 아래에:

동아리 리스트 (인원수, 최근 활동 미리보기)
"동아리 만들기" 버튼 ("모임 만들기"와 구분 — 모임=1회성 번개, 동아리=지속적 그룹)

3. 캐릭터 상호작용 강화

동아리 회원끼리는 캐릭터에 뱃지/아이콘 표시 (예: 러닝크루면 운동화 아이콘)
지도에서 같은 동아리원끼리 있으면 특별 이펙트나 채팅창 자동 그룹화

4. 동아리 활동 인증/기록

산책 동아리라면 "오늘 금강 산책길 완주" 같은 체크인 기능
활동 기록이 쌓이면 캐릭터 레벨업이나 뱃지 획득 → 게임화 요소

5. 동네 게시판 / 이벤트 캘린더

"동네 대화 참여하기" 버튼처럼, "동아리 모집 게시판" 버튼 추가
다가오는 동아리 정기모임을 캘린더나 지도 위 "오늘의 이벤트" 마커로 표시

6. 추천 알고리즘

사용자 관심사(산책, 사진, 커피 등 — 스크린샷의 "가람: 커피 한 잔 어때요?" 같은 소개글 활용)를 기반으로 동아리 추천
```
