# 호수공원 충녕이 실제 세종 장소 첫 추천 및 내부 카카오지도 연결

- **ID**: 044
- **날짜**: 2026-08-09
- **유형**: 기능 추가

## 작업 요약

세종호수공원 NPC 충녕이의 첫 대화를 실제 카카오 Local 장소 하나를 즉시 추천하는 전용 프롬프트로 변경했다. 운영에서 누락됐던 WIZ 추천 API를 추가하고 추천 장소의 좌표를 대화 내부 HTML 카카오지도 iframe에 연결했다.

## 원문 요청사항

```text
충녕이와 대화 1. 첫 대화에서는 자신을 짧게 소개한다.
2. 자신을 '오늘 가볼 세종 장소를 추천해주는 충녕이'라고 자연스럽게 설명한다.
3. 이어서 제공된 장소 하나를 바로 추천한다.
4. 장소 이름은 제공된 실제 장소명을 그대로 사용한다.
5. 후보에 없는 장소를 새로 만들어내지 않는다.
6. 확인되지 않은 영업시간, 가격, 메뉴, 별점 등의 정보를 만들지 않는다.
7. 사용자의 성격이나 취향을 임의로 분석하지 않는다.
8. 너무 관광 안내원처럼 길게 설명하지 않는다.
9. 밝고 친근한 말투로 2~3문장 이내로 말한다.
10. "궁금한 것이 있으면 물어봐", "자유롭게 둘러봐" 같은 일반 챗봇 안내는 하지 않는다.
11. 핵심은 항상 '오늘 여기 한번 가보는 건 어때?'라는 추천이다.
이런세종호수공원 npc 충녕이 프롬프트 작성해주고 이것으로 카카오 지도 api연결해서 세종 장소 플레이어가  내부html로 위치도 볼 수 있게 해줘
```

## 변경 파일 목록

- `src/app/page.home/api.py`: 충녕이 단일 프롬프트, 카카오 Local 실제 장소 검색, OpenAI 제한 응답 API
- `react-app/server/src/routes/realPlaceRecommendations.ts`: 개발 서버 프롬프트와 좌표 응답 일치
- `react-app/src/pages/GamePage.tsx`: 첫 대화 자동 추천 및 내부 카카오지도 iframe
- `react-app/src/pages/GamePage.css`: 대화 내부 지도 레이아웃
- `react-app/scripts/reviewOpsRegression.test.ts`: 실제 장소·프롬프트·내부 지도 회귀 검사
- `src/app/page.home/view.pug`: 운영 iframe 빌드 식별자 갱신
- `src/assets/jochwon-app/`: 운영 프로덕션 번들 갱신
