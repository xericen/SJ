## 작업 요약

기존 소셜·이메일 중심 가입/로그인 UI를 휴대폰 번호와 문자 인증번호만 사용하는 흐름으로 변경했다.
서비스의 “멀티버스” 명칭은 세종 지역성을 드러내는 “세종마실”로 바꾸고, 가입 절차를 휴대폰 인증·닉네임·관심사·캐릭터·현장 입장의 5단계로 재구성했다.

## 원문 요청사항

```text
회원가입 & 로그인 페이지 수정

멀티버스 -> 세종과 관련된 이름으로 변경해서 입장 준비하면 될 거 같아.

회원가입 모드
1.  계정 만들기
카카오, 구글과 같은 거 빼줘, 당근처럼 휴대폰 번호만으로 가입이 가능하게 해줘. *동일한 휴대폰 번호로 여러 계저을 만들 수 없으며, 중복가입은 제한되게, 휴대폰 번호 입력하고, 문자로 받은 인증번호 자리 입력 -> 인증 완료되면 자동으로 다음 단계 넘어감
-> 닉네임 설정 -> 관심사 -> 캐릭터 -> 현장 입장
```
