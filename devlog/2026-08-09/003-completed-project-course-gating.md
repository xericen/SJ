# 완료 프로젝트 일정표 기반 02→03 확정 흐름 및 AI·카카오 장소 추가

- 원 요청: 02에서 내가 만들거나 참여해 프로젝트실에서 완성한 프로젝트만 가져오고, 팀 일정표를 홀로그램에 표시하며, 장소 추가 시 전체 프로필 기반 AI가 카카오 실제 세종 장소를 추천. 불러오기 전에는 02 내용을 숨기고 일정 확정 전에는 03을 비우며 QR·PDF 제거.
- 변경 파일: `react-app/src/components/GovernmentCentralPlazaWebUI.tsx`, `devlog.md`, 본 상세 기록.
- 변경 내용: 로그인 닉네임이 리더 또는 멤버인 `completed` 프로젝트만 필터링하고 프로젝트실의 최종 코스 handoff와 프로젝트별 draft 일정표를 우선 불러온다. 불러오기 전 홀로그램·분석 결과를 잠그고 AI 추천 후에만 분석 결과를 표시한다. 장소 추가는 전체 프로필로 OpenAI가 카카오 Local 후보 중 실제 세종 장소를 고른다. 03은 02에서 확정·저장된 코스만 표시하며 QR·PDF 버튼은 제공하지 않는다.
- 확인: React TypeScript/Vite/서버 빌드 성공, 성능 예산 검증 성공, QR·PDF 문자열 미존재 확인.
- 남은 리스크: OpenAI 또는 카카오 API 장애 시 장소 자동 추가는 실패 안내를 표시한다. 여러 완료 프로젝트가 있으면 현재 가장 먼저 조회된 프로젝트를 불러온다.
