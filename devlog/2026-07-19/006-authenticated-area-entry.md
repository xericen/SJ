# 006 로그인 상태 동네 입장 인증창 반복 노출 수정

## 원문 요청사항

```text
로그인을 한 상태에서 방에 들어가려고 하니ㄲ 다시 회원가입 or 로그인을 하라는 창이 떠, 이 부분 해결해줘
```

## 작업 내용

- 동네 카드의 입장 버튼이 로그인 여부와 관계없이 회원가입 창을 직접 열던 원인을 수정했습니다.
- 공통 `enterArea` 흐름을 추가해 로그인 사용자는 선택한 동네로 바로 입장하고, 비로그인 사용자에게만 인증 창을 표시하도록 분기했습니다.
- 메인 시작 버튼에도 같은 로그인 상태 분기를 적용했습니다.
- 로그인 상태에서는 버튼 문구를 `입장하기`, `내 동네 입장하기`로 표시하도록 개선했습니다.

## 확인 결과

- WIZ 일반 빌드 성공
- 생성된 빌드 결과에서 동네 입장 버튼이 `enterArea(area)`를 호출하는지 확인
- `enterArea`가 세션 사용자 존재 시 인증 창을 열지 않고 동네 선택 및 입장 안내를 처리하는지 확인
- 비로그인 상태에서는 기존 회원가입 창이 유지되는지 코드 경로 확인

## 참고

- 현재 화면 구조에는 별도의 방 상세 페이지가 없어, 기존 동네 둘러보기 화면 안에서 선택 동네 입장 상태와 안내 메시지를 표시합니다.
