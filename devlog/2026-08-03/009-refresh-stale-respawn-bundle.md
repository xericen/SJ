# 구버전 리스폰 번들 강제 갱신

- **ID**: 009
- **날짜**: 2026-08-03
- **유형**: 버그 수정

## 작업 요약

운영 최신 번들에는 제거된 Socket.IO 리스폰 오류가 열린 리뷰 iframe의 메모리·캐시에 남아 계속 표시되는 문제를 확인했다.
배포 버전이 달라지면 캐시와 기존 서비스워커를 정리하고 최신 해시 번들 주소로 한 번만 재진입하도록 정적 앱 진입점을 보강했다.

## 원문 요청사항

```text
리스폰 저장 응답이 없습니다. 변경된 서버 코드를 재시작한 뒤 다시 시도해 주세요. 이렇게 뜨는데 해결해줘.
```

## 변경 파일 목록

- `react-app/index.html`: 배포 버전 확인, 캐시·서비스워커 정리, 최신 버전 URL 재진입 처리 추가
- `src/assets/jochwon-app/`: 갱신된 React 프로덕션 진입점과 번들 동기화
- `devlog.md`, `devlog/2026-08-03/009-refresh-stale-respawn-bundle.md`: 작업 이력 기록

## 확인 결과

- 운영 최신 소스와 번들에서 기존 `리스폰 저장 응답이 없습니다` 문구가 존재하지 않음을 확인
- React·Vite·Express 전체 빌드 성공
- WIZ 일반 빌드 성공
- React `dist`와 WIZ 정적 자산이 각각 128개 파일로 일치
- 공개 `index.html`에서 `20260803-respawn-v3` 버전 갱신 코드 제공 확인
- 공개 공용 리스폰 레코드 조회 정상 및 `git diff --check` 성공

## 남은 리스크

- 이미 열려 있던 구버전 탭은 새 진입점 코드를 받기 위해 한 번의 새로고침 또는 재접속이 필요하다.
- 브라우저 자동화 도구가 없는 환경이라 리뷰 iframe 내부의 실제 자동 재진입 화면은 수동 확인이 필요하다.
