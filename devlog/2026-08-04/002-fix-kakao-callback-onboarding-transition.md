# 카카오 인증 성공 콜백의 초기설정 1단계 전환 유실 방지

- **ID**: 002
- **날짜**: 2026-08-04
- **유형**: 인증 흐름 버그 수정

## 작업 요약

카카오 인증 성공 팝업이 원래 화면에 결과 메시지를 전송한 직후 닫혀, 제한된 ReviewOps iframe에서 초기설정 화면 전환이 유실될 수 있던 경합 조건을 수정했다.
원래 화면이 성공 메시지 수신 확인을 콜백 창에 회신한 뒤에만 팝업을 닫도록 변경했다.
수신 확인이 오지 않으면 콜백 창 자체가 1.2초 후 초기설정 성공 URL로 이동하도록 복구 경로를 추가했다.
WIZ 운영 프로세스의 이전 Python 코드 캐시도 공식 빌드 API로 비워 새 콜백을 즉시 반영했다.

## 원문 요청사항

```text
카카오톡 인증화면 인증했는데 그 다음 페이지인, 캐릭터 설정 1화면이 안 나와, 제대로 카카오톡 인증이 된건지 확인하고 수정해줘
```
