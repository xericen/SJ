# 정부청사 진입 게이트 판정 수정

- 원 요청: 체험용에서 내 프로필 완성도 67인데 정부청사 안 넘어가짐, 원인을 찾고 해결해줘.
- 변경 파일: `src/assets/jochwon-app/assets/GamePage-CRcC7DUd.js`
- 변경 내용: 정부청사 이동 시 계산된 `completion`과 체험용 프로필의 `profileCompletion` 중 높은 값을 사용하도록 수정했다. 기존에는 계산 객체의 `completion`만 검사해 67%가 0으로 판정될 수 있었다.
- 확인: 현재 운영 엔트리 `index-BNOnJQOS.js`가 로드하는 `GamePage-CRcC7DUd.js`에서 수정된 조건을 확인했다. 67%는 50% 게이트를 통과하고, 50% 미만은 기존 차단 이벤트를 유지한다.
- 남은 리스크: 실제 브라우저에서 로그인 세션별 프로필 데이터로 진입을 재현하는 자동 E2E 환경은 제공되지 않아 운영 화면 재확인은 필요하다.
