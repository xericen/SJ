## 작업 요약

캐릭터 생성 화면에서 동작하지 않던 얼굴·헤어·의상·액세서리·표정·모션 카테고리 버튼을 실제 선택 가능한 탭으로 변경했다.

## 남은 리스크

- 캐릭터 미리보기는 CSS 기반 프로토타입이며 실제 캐릭터 에셋 저장이나 서버 프로필 반영은 아직 연동되지 않았다.
