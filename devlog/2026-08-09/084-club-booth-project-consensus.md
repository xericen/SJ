# 동아리 멤버 콘텐츠 권한·공용 부스 및 프로젝트 전원 합의 연결

## 사용자 원문 요청

> 로그인하고 가입한 사람만 이번달 활동이랑 공유 사진 볼 수 있게, 댓글달 수 있게 해주고, 다른 사람 동아리 +에 넣었는데 연동이 안되어서 다른 사람에게는 안 보임, 그래숴 다른 사람이 +에 동아리 넣어두었는데도 불구하고 +로 추가할 수 있음 이 부분 해결해줘. 프로젝트실 들어와서 프로젝트 시작시 프로젝트 팀장만 역할 배분 가능, 아이디어 보드에서 ai 회의도우미 빼고, 장소 추가할 떄 카카오맵 api연결해서 장소 검색할 수 있게 해줘. 최종합의 검토 누르면 플젝트에 참가한 사람에게 모두 중앙에 최종 합의 검토하겠습니까? 창 뜨게하고 거절 수락할 수 있게 해줘, 모두 수락하면 프로젝트 완성으로 하면됨.

## 변경 내용

- 로그인 후 가입한 동아리 멤버만 이번 달 활동·공유 사진을 열람하고 댓글을 작성하도록 제한했다.
- 동아리 부스 번호를 공용 DB에 저장하고 서버에서 중복 배치를 차단했다.
- 프로젝트 팀장만 역할과 최종 검토 요청을 변경할 수 있도록 제한했다.
- 아이디어 보드의 AI 회의 도우미를 제거하고 기존 서버측 카카오 Local 장소 검색을 주 동선으로 표시했다.
- 최종 검토 요청과 참가자별 수락·거절을 WIZ 공용 데이터에 저장하고 2초 간격으로 동기화한다.
- 프로젝트 참가자 전원이 수락했을 때 프로젝트를 완료 상태로 저장하고 방문 코스로 연결한다.
