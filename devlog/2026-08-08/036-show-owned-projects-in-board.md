# 프로젝트실 생성 프로젝트 둘러보기 노출

- 원본 요청: 프로젝트실 로비 키오스크에서 만든 프로젝트가 프로젝트 둘러보기에 표시되고, 다른 사람은 신청할 수 있지만 프로젝트 소유자는 자기 프로젝트에 신청하지 못하게 해 달라는 요청.
- 변경 파일: `react-app/src/components/ProjectRoomInteractions.tsx`
- 변경 내용: 프로젝트 둘러보기 필터에서 현재 사용자가 소유한 공개 모집 프로젝트를 제외하지 않도록 수정했다. 소유 프로젝트에는 상세 보기만 제공하고 참가 신청은 표시하지 않으며, 타 사용자의 프로젝트에는 기존 신청 흐름을 유지했다. 생성 시 기존 `saveProjectRoomProjects`의 서버 동기화 경로도 그대로 사용된다.
- 검증: `npm run build` 성공 및 성능 예산 검사 통과.
