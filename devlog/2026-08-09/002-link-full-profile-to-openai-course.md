# 01 전체 프로필 전달본을 02 OpenAI 코스 분석에 연결

- 원 요청: 01의 AI 추천 연결 버튼을 눌렀을 때 데이터가 실제로 02에 전달되게 하고, 주거지역·세종 방문 경험·MBTI를 포함한 전체 프로필 중심으로 OpenAI 장소·코스 추천을 수행.
- 변경 파일: `react-app/src/components/GovernmentCentralPlazaWebUI.tsx`, `react-app/server/src/services/ai/governmentCourse.ts`, `devlog.md`, 본 상세 기록.
- 변경 내용: 01 버튼 클릭 시 현재 계정의 전체 프로필, 체험 기록, 완료 프로젝트를 계정 확인이 포함된 전달본으로 저장한다. 02는 해당 전달본이 없으면 OpenAI 최적화를 실행할 수 없고, 저장된 전달본의 주거지역·세종 방문 경험·MBTI·관심사·이용 목적·선호 장소·프로젝트 협업 정보를 서버 요청에 포함한다. 서버 스키마와 OpenAI 프롬프트도 전체 프로필을 중심 근거로 사용하도록 확장했다.
- 확인: React TypeScript/Vite/서버 전체 빌드 성공, 성능 예산 검증 성공.
- 남은 리스크: 프로필 수정 후에는 01에서 연결 버튼을 다시 눌러야 최신 프로필 전달본으로 갱신된다. OpenAI 설정 또는 네트워크 장애 시 맞춤 규칙 결과로 대체된다.
