# 호수공원·축제부스 포탈 라벨 크기 통일 및 공동캠퍼스 라벨 하향

- 원본 요청: `세종호수 공원 포탈 제목 크기 축제부스 제목 크기랑 동일하게 변경해주고, 공동캠퍼스 제목은 안 보여서 아래로 내려서 위치 옮겨줘`
- 변경 파일: `react-app/src/game/renderers/VillageMapRenderer.ts`, `react-app/scripts/portalLabelLayout.test.ts`
- 변경 내용: 세종호수공원과 축제부스의 포탈 라벨을 동일한 compact 스프라이트 크기로 지정하고, 공동캠퍼스 목적지 라벨의 세로 위치를 낮췄다.
- 확인: 포탈 라벨 크기·위치 정적 테스트 후 React 번들 생성 및 WIZ 운영 빌드를 진행한다.
- 남은 리스크: 실제 카메라 각도와 포탈 주변 오브젝트에 따라 가독성은 화면별로 달라질 수 있다.
