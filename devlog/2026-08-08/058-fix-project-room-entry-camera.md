# 프로젝트실 내부 입장 시 카메라 오른쪽 회전 즉시 적용

- 사용자 원 요청: 프로젝트 로비에서 프로젝트를 완성한 뒤 내부로 들어가 프로젝트실에 진입할 때 카메라가 오른쪽으로 회전하지 않는 문제 수정.
- 변경 파일: `react-app/src/game/renderers/VillageMapRenderer.ts`
- 변경 내용: `project-room-instance-enter` 이벤트를 렌더러가 직접 수신하고, 내부 입장 버튼을 누르는 즉시 프로젝트실 카메라 방위각을 `-90`도로 설정하도록 수정. 기존 문 통과 후 처리와 이벤트 해제도 유지.
- 확인 결과: WIZ `main` 프로젝트 빌드 성공, 이벤트 등록·처리·해제 코드 확인, 운영 `/home?_build=20260808-project-room-camera-v1` HTTP 200 확인.
- 남은 리스크: 자동 환경에서 실제 클릭 및 픽셀 단위 카메라 화면 검증은 제한되므로 사용자 브라우저에서 내부 입장 동작을 최종 확인해야 함.
