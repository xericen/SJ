# 005 MySQL 회원가입·로그인 연동

## 원문 요청사항

```text
[보안상 비공개] MySQL DB로 연결해서 회원가입, 로그인을 모두 연결해줘.
```

## 작업 내용

- 제공된 MySQL 서버에 프로젝트 전용 데이터베이스와 `user` 테이블을 준비했습니다.
- 프로젝트 DB 설정을 MySQL로 연결하고 배포 환경에서 환경변수로 접속 정보를 덮어쓸 수 있게 구성했습니다.
- 홈 회원가입·로그인 API를 추가하고 이메일 정규화, 서버 검증, 중복 가입 방지, bcrypt 비밀번호 해시, 세션 생성·조회·해제를 연결했습니다.
- 홈 화면에서 실제 API를 호출하고 처리 중 상태, 서버 오류, 로그인 사용자 표시, 로그아웃을 반영했습니다.
- MySQL 최신 인증 방식 연결에 필요한 `cryptography` 패키지를 실행환경에 설치했습니다.

## 확인 결과

- WIZ 클린 빌드 성공
- MySQL 프로젝트 사용자 테이블 및 이메일 고유 인덱스 생성 확인
- 실제 서비스 API 회원가입 성공 확인
- 동일 이메일 중복 가입 409 차단 확인
- 로그인 세션 조회 및 로그아웃 후 세션 해제 확인
- 이메일 대소문자 정규화 후 재로그인 성공 확인
- 저장 비밀번호가 평문이 아니며 bcrypt 검증을 통과하는지 확인
- 검증용 임시 사용자 데이터 삭제 완료

## 참고

- 실제 호스트, 계정, 데이터베이스명, 비밀번호는 공개 저장소에서 비공개 처리했습니다.
- 운영 환경에서는 `SJ_DB_PASSWORD` 환경변수와 전용 최소 권한 DB 계정을 사용해야 합니다.
