# 중앙광장 PROJECT→AI→VISIT 순환 구조

- 원 요청: 여행 일정 저장 결과를 내 프로필 추천 코스에 넣고 01 프로젝트, 02 AI 일정 확정, 03 일정 및 방문 전광판을 역할에 맞게 분리하며 방문 인증을 다시 프로필에 반영.
- 변경 파일: 중앙광장 3단계 UI·스타일, 프로필·분석·체험 하네스, 런타임 식별자, 회귀 테스트, 운영 정적 자산, 개발 로그.
- 변경 내용: 01은 실제 프로필·체험 데이터 준비, 02는 AI 분석·코스 편집·최적화·확정, 03은 QR·카카오지도·방문 인증 화면으로 분리했다. 확정 일정은 프로필 추천 세종 코스에 즉시 표시되고 방문 인증은 활동 기록과 다음 분석에 반영된다.
- 확인: 런타임 회귀 테스트 5건 통과, React TypeScript/Vite/서버 빌드 및 성능 예산 검증 성공, WIZ `main` 빌드 성공, 운영 반영 확인.
- 남은 리스크: QR은 현재 방문용 안내 동작이며 외부 시설의 실제 검증 QR 시스템과는 연동되지 않는다.
