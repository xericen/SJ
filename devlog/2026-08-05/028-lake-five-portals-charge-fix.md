# 세종호수공원 5개 포탈 3초 대기 이동 판정 보강

## 사용자 원문 요청

> 세종호수 공원에서 각 5개의 포탈로 3초 기다려야지 이동할 수 있게 하는 거 다시 한 번 잘 작동하는지 확인해줘, 세ㅔ종예술의 전당 포탈 위에 서있는데 작동이 안됨. 5개 다 직접 확인해보고 결과알려줘. 그리고 수정해줘

## 변경 파일

- `src/assets/jochwon-app/assets/GamePage-vnOFqgno.js`
  - 베어트리파크·공동캠퍼스·세종예술의전당·축제부스·먹거리부스 5개 포탈 모두 3초 충전 설정을 유지했습니다.
  - 포탈 시각 영역과 진입 판정 간격을 맞추기 위해 5개 포탈의 활성 반경을 112로 통일했습니다.
  - 포탈별 활성 반경을 실제 진입 판정에서 우선 사용하도록 수정했습니다.
- `src/assets/jochwon-app/index.html`
  - 변경 번들 반영을 위한 빌드 ID를 갱신했습니다.
- `src/app/page.home/view.pug`
  - iframe 빌드 쿼리를 새 빌드 ID와 일치시켰습니다.

## 검증 결과

- 5개 포탈 각각에 대해 목적지, 3초 충전값, 활성 반경을 자동 검증했습니다.
- 60fps 기준 각 포탈이 180프레임 이전에는 이동하지 않고 180프레임에서 이동하는 것을 시뮬레이션했습니다.
- 변경 번들의 JavaScript 구문 검사와 WIZ 프로젝트 일반 빌드를 통과했습니다.
