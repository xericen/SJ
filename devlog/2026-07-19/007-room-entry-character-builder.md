# 007 동네 방 입장 화면 및 회원가입 캐릭터 제작 복구

## 원문 요청사항

```text
입장하기를 클릭하면 입장해야하는데 그 페이지로 안 넘어가, 이 부분 수정해줘. 그리고 회원가입 페이지에서 캐릭터 만드는 페이지 있어야하는데 사라졌어, 다시 생성해줘
```

## 작업 내용

- 로그인 사용자가 동네 카드의 `입장하기`를 누르면 실제 동네 방 화면으로 전환되도록 입장 상태를 수정했습니다.
- 동네별 지도, 주변 이웃, 인사·모임·대화 버튼과 방 나가기 동선을 포함한 입장 화면을 추가했습니다.
- 사용자의 전신 캐릭터를 방 지도에 표시하고 데스크톱 방향키 이동을 연결했습니다.
- 회원가입을 계정 → 관심사 → 캐릭터 → 위치 확인의 4단계로 확장했습니다.
- 얼굴 피부톤, 헤어, 의상, 액세서리, 신발을 선택하거나 무작위 조합할 수 있는 전신 캐릭터 제작 화면을 복구했습니다.
- 선택한 캐릭터를 브라우저에 저장해 가입 완료 후 방 화면에 동일하게 표시하도록 연결했습니다.

- 전신 캐릭터의 머리·얼굴·몸·다리·신발 구조와 선택 스타일 포함 확인

## 참고

- 캐릭터 설정은 현재 브라우저 로컬 저장소에 저장되며, 다른 기기와 동기화되는 서버 프로필 저장은 아직 연결되지 않았습니다.
- 주변 이웃·모임·대화 내용은 현재 화면용 샘플 데이터입니다.
