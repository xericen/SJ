# 세종한바퀴

세종한바퀴는 아바타로 세종의 자연·문화·축제·먹거리·캠퍼스를 탐험하고, 탐험 과정에서 쌓인 취향과 활동 기록을 실제 세종 방문 코스로 연결하는 3D 소셜 월드입니다.

가상 공간을 둘러보는 데서 끝나지 않고 사용자가 세종에 흥미를 느끼고 실제로 방문하도록 돕는 것이 프로젝트의 목표입니다.

> 배포 사이트의 게스트용 공간 미리보기에서 총 17개 월드와 실제 인게임 GLB 기반 3D 미리보기를 확인할 수 있습니다.

## 배포 사이트

[https://sj.wizide.com/home](https://sj.wizide.com/home)

로컬 환경에서는 MySQL 서버 IP에 접근할 수 없어 데이터베이스 연동 기능을 정상적으로 이용하기 어렵습니다. 전체 기능은 배포 사이트에서 체험하는 것을 권장합니다.

## 전체 사용자 여정

```text
세종 탐험 → 취향 발견 → 활동 기록 → 사람과 프로젝트 연결
          → AI 방문 코스 생성 → 실제 세종 방문
```

사용자는 세종호수공원에서 탐험을 시작해 베어트리파크, 공동캠퍼스, 정부청사로 이동합니다. 공연 저장, 먹거리 관심, 축제 체험, 꽃 채집, 동아리와 프로젝트 활동은 프로필 데이터로 이어지고, 중앙광장 AI가 이를 실제 세종 방문 코스에 반영합니다.

## 프로젝트 차별점

- **탐험에서 실제 방문까지:** 3D 공간의 선택과 활동을 일회성 체험으로 끝내지 않고 실제 세종 방문 코스로 전환합니다.
- **행동 기반 개인화:** 설문만 사용하는 대신 공연 저장, 꽃 채집, 축제·먹거리 관심과 협업 기록을 AI 추천 근거로 활용합니다.
- **지역 데이터 기반 추천:** Kakao Local API에서 확인한 실제 세종 장소 안에서만 추천해 생성형 AI의 장소 환각을 줄입니다.
- **소셜 협업 흐름:** 모집글, 동아리 승인, 프로젝트 역할·아이디어 공유와 전원 합의를 하나의 방문 계획으로 연결합니다.
- **운영 가능한 결과물:** 17개 월드, 로그인·게스트 분리, MySQL 저장, 실시간 동기화와 운영 배포까지 구현했습니다.

## 월드별 주요 기능

### 세종호수공원

서비스가 시작되는 중심 월드입니다. 충녕이 NPC가 첫 방문자에게 이동 방법과 주요 공간을 안내합니다.

- 세종예술의전당, 먹거리 부스, 축제 부스로 이동
- 베어트리파크와 공동캠퍼스로 이어지는 포털 탐험
- 충녕이에게 오늘 방문할 세종 장소를 추천받는 기능
- 카카오 Local API의 실제 세종 장소와 OpenAI 추천 문구 활용
- 추천 장소를 게임 내부 HTML 지도에서 확인

#### 세종예술의전당

- 세종에서 열리는 뮤지컬·공연 소개
- 실제 공연 티저와 포스터 확인
- 관심 공연 저장 및 프로필 기록 반영

#### 먹거리·축제 부스

- 세종의 실제 카페·음식점과 지역 먹거리 소개
- 카카오맵 기반 장소 위치 확인
- 세종 축제의 상세 정보와 티저 영상 확인
- 관심·열람·체험 활동을 AI 추천 근거로 기록

### 베어트리파크

#### 곰 체험소

- 먹이 5개를 찾아 곰에게 순서대로 주기
- 먹이를 먹은 곰이 GLB 애니메이션 중 하나를 무작위로 재생
- 5회 완료 시 마이홈에 곰 동상 해금

#### 수목원과 마이홈

- 여러 종류의 꽃과 식물을 발견해 도감에 기록
- 채집한 꽃을 마이홈 정원에 최대 5개까지 배치
- 식물 5·10·14종 발견에 따라 기억나무 성장
- 기억나무에서 탐험 감정을 담은 편지 작성
- 마이홈의 꽃밭·곰 동상·실내 공간과 상호작용

기억나무 기록은 탐험 기록을 공개한 로그인 사용자에게 제공됩니다. 게스트 기록은 공개되지 않습니다.

### 공동캠퍼스

- 모집센터에서 모집글 작성·조회·참여
- 동아리 거리제에서 동아리 생성·가입·역할 관리
- 학생회관에서 사용자가 활동 중인 공간 확인
- 프로젝트실에서 동아리 기반 프로젝트 생성
- 장소·테마·먹거리·역할·아이디어를 협업 테이블에 누적
- 새로고침으로 다른 참여자가 저장한 최신 내용 확인
- 최종 합의는 협업 참여자 전원의 동의 후 완료

프로젝트실에서 완성된 코스는 정부청사 중앙광장으로 가져와 AI 분석과 실제 방문 일정 생성에 사용할 수 있습니다.

### 정부청사

프로필 완성도가 일정 기준에 도달하면 정부청사 이동로가 해금됩니다.

#### 전망대·스마트시티

- 전망대에서 높은 건물 위에서 세종을 내려다보는 경험
- AI·자율주행·스마트 에너지 등 세종 스마트시티 전시
- 실제 GLB 기반 3D 전시와 공간 안내

#### 중앙광장 AI 방문 코스

```text
PROJECT → AI → VISIT
```

1. **PROJECT**: 완료된 협업 프로젝트와 코스를 불러옵니다.
2. **AI**: 프로필·활동 기록을 분석하고, 프로젝트 코스에 세종의 실제 장소를 추가·보완합니다.
3. **VISIT**: 확정된 방문 순서와 일정을 저장하고 화면 안 지도에서 확인합니다.

카카오 로그인 사용자는 관심사, 역할, 선호 장소, 이용 목적, 거주지역, 세종 방문 경험, MBTI와 누적 행동 기록을 분석에 사용합니다. AI는 제공된 후보 장소 범위 안에서만 최대 4곳을 추천하며, 장소·주소·운영 정보를 임의로 만들어내지 않도록 제한합니다.

## 중앙광장 AI 추천 원칙

| 원칙 | 적용 내용 |
|---|---|
| 추천 범위 | 입력으로 제공된 실제 세종 후보 장소 안에서만 추천 |
| 정보 정확성 | 확인되지 않은 장소·주소·운영 정보 생성 금지 |
| 분석 정보 | 사용자가 제공하거나 서비스에 저장한 프로필·활동만 사용 |
| 조건 반영 | 이동 수단, 시간, 예산, 동행 조건 반영 |
| 체험 연결 | 축제·식물·캠퍼스 경험이 추천에 반영된 이유 설명 |
| 결과 형식 | 최대 4곳의 방문 순서와 추천 근거를 간결한 한국어로 생성 |

## AX 적용 방식

세종한바퀴의 AX는 AI 기능을 별도 메뉴로 분리하는 것이 아니라 탐험의 각 행동이 다음 경험으로 이어지도록 설계한 것입니다.

| 단계 | AX 적용 방식 |
|---|---|
| 안내 | 충녕이 NPC가 첫 월드와 이동 경로 안내 |
| 취향 발견 | 공연·먹거리·축제 선택을 관심 기록으로 저장 |
| 자연 탐험 | 꽃 채집·식물 관찰을 프로필 성장 데이터로 연결 |
| 사람 연결 | 동아리·모집글·프로젝트 활동을 방문 계획과 연결 |
| 코스 생성 | 중앙광장 AI가 프로필과 활동 기록을 분석해 방문 코스 생성 |

## 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 서비스 호스트 | WIZ Framework, Angular |
| 3D 클라이언트 | React, TypeScript, Vite |
| 3D·게임 | Three.js, Phaser, GLB/GLTF, `<model-viewer>` |
| 백엔드 | Python WIZ App API, Node.js, Express |
| 실시간 통신 | Socket.IO |
| 데이터베이스 | MySQL 8, WIZ ORM, `mysql2` |
| 지역 데이터 | Kakao Local API, 세종시·관광 데이터 API |
| AI | OpenAI API |

### 기술 설계 핵심

- React 3D 클라이언트는 WIZ 정적 번들로 배포하고, Python WIZ API와 Express API가 인증·활동·협업 데이터를 처리합니다.
- 카카오 로그인 사용자의 진행도는 MySQL을 기준으로 복원하며, 게스트 데이터는 로그인 계정 기록과 분리합니다.
- Socket.IO 룸과 서버 revision을 사용해 캐릭터 이동과 프로젝트 역할·아이디어·코스 변경을 사용자 사이에 동기화합니다.
- AI 추천은 저장된 프로필과 활동 기록, Kakao Local API에서 확인한 실제 세종 장소만 입력으로 사용합니다.
- TypeScript 검사, 서버 테스트, 회귀 테스트, 프로덕션 빌드와 WIZ 번들 비교로 배포 상태를 검증합니다.

## 로컬 실행

```bash
git clone https://github.com/xericen/SJ.git
cd SJ/react-app
npm install
cp .env.example .env.local
npm run dev
```

Express 서버와 데이터베이스가 필요한 기능은 `react-app/server/.env.example`을 참고해 별도 환경변수를 설정해야 합니다. 실제 API 키, DB 비밀번호, 세션 비밀값은 `.env` 파일에만 저장하고 저장소에 커밋하지 않습니다.

## 이용 시 참고사항

- 카카오 로그인은 테스트 로그인 대상자로 등록된 사용자만 가능합니다.
- 로컬 환경에서는 MySQL 서버 IP 제한으로 로그인 사용자용 저장 기능이 정상 동작하지 않을 수 있습니다.
- 전체 기능 체험은 [배포 사이트](https://sj.wizide.com/home)를 권장합니다.
- 모집센터·학생회관의 일부 정보와 게스트용 추천 데이터는 더미 데이터일 수 있습니다.
