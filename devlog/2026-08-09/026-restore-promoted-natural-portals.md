# 체험용 자연 맵 포탈 공용 저장 좌표 복구

## 사용자 요청

> 세종호수공원에서 직접 옮긴 포탈 위치를 고정해 달라고 했는데 기존 위치로 돌아간 원인을 찾아 다시 수정해 주세요.

## 원인 및 변경 내용

- 체험 브라우저에서 옮긴 자연 맵 좌표는 공용 레이아웃 DB에 정상 승격되어 있었다.
- 공용 좌표 조회기가 세종호수공원·베어트리파크 키를 고정 키로 판정해 DB 값을 제외하고 코드 기본값을 다시 합치던 것이 원인이었다.
- 자연 맵 8개 키는 잠금 상태에서도 승격된 DB 좌표를 읽도록 예외 처리해 사용자가 저장한 위치를 모든 체험 사용자에게 적용한다.
- 잘못된 기본 좌표로 생성된 1차 잠금을 우회하고, 원래 좌표를 가진 체험 브라우저가 한 번만 다시 승격할 수 있는 보정 잠금 v2를 추가했다.
