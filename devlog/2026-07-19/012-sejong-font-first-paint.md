# 첫 화면 세종 글꽃체 선로딩 및 전환 깜빡임 제거

## 사용자 요청

> 웹에 들어가면 기본 글씨다가 글꽃체로 바뀌거든? 이 부분 해결해줘, 새로고침해서 들어와도 글꽃체로 시작할 수 있게 해주면 좋을 거 같아

## 변경 내용

- HTML 진입 시 세종 글꽃체 파일을 `preload`하여 스타일 계산 전부터 내려받도록 했다.
- 글꼴 표시 정책을 `swap`에서 `block`으로 변경해 기본 글꼴이 먼저 노출되지 않도록 했다.
- 세종 글꽃체가 준비될 때까지 본문을 숨기고, 로딩 완료 직후 표시하도록 초기화 스크립트를 추가했다.
- 글꼴 요청 실패 시 화면이 계속 숨겨지지 않도록 10초 안전 해제를 추가했다.

## 변경 파일

- `src/angular/index.pug`
- `src/angular/styles/styles.scss`

## 확인 결과

- `wiz project build --project=main` 성공
- 빌드 산출물에서 글꼴 선로딩 링크, 초기 숨김 처리, 글꼴 준비 후 표시 로직 확인
- 로컬 글꼴 요청의 HTTP 200 및 `font/ttf` 응답 확인
- 번들 산출물에 세종 글꽃체 파일이 포함된 것을 확인

## 남은 리스크

- 약 7.5MB인 TTF 원본을 사용하므로 네트워크가 매우 느린 환경에서는 첫 화면 표시가 지연될 수 있다.
- 글꼴 요청이 실패하면 10초 뒤 안전 해제되어 대체 글꼴로 표시된다.
