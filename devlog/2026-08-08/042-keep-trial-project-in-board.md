# 체험용 프로젝트 둘러보기 유지

- 원본 요청: 프로젝트실에서 만든 프로젝트가 프로젝트 둘러보기에 표시되지 않는 문제 수정.
- 변경 파일: `react-app/src/services/projectRoomProjects.ts`
- 변경 내용: 체험용 프로젝트 목록을 세션 저장소에 보관하고, 실시간 원격 조회 결과와 병합한다. 따라서 생성 직후 원격 응답이 늦거나 누락되어도 프로젝트실 내 둘러보기와 내 프로젝트에서 유지된다. 게스트가 공동캠퍼스로 나갈 때 저장소도 함께 삭제된다.
- 검증: React 및 WIZ 빌드 후 운영 번들 확인.
