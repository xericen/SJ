# 전체 맵 좌측 현재 위치·현재 활동 HUD 연결

- 사용자 원 요청: 공동캠퍼스에서 떨어져 보이는 `현재 위치`와 `현재 활동 중` 패널을 다른 맵에서도 서로 붙도록 수정.
- 변경 파일: `react-app/src/pages/GamePage.css`
- 변경 내용: 모든 맵과 반응형 화면에서 좌측 활동 패널의 최종 `top`·`left`를 위치 카드 하단에 맞추고, 연결부의 위쪽 모서리 라운딩을 제거해 하나의 HUD 스택처럼 보이도록 고정.
- 확인 결과: WIZ `main` 빌드 성공, 공통 최종 CSS 규칙 반영 확인, 운영 `/home?_build=20260808-left-hud-stack-v1` HTTP 200 확인.
- 남은 리스크: 실제 각 맵의 브라우저 화면 캡처는 환경상 제한되어 사용자 화면에서 최종 픽셀 확인이 필요함.
