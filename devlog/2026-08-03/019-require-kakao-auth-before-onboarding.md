# 카카오 인증 화면을 필수로 거친 뒤 초기설정 진입하도록 수정

- **ID**: 019
- **날짜**: 2026-08-03
- **유형**: 인증 흐름 버그 수정

## 작업 요약

카카오에 기존 로그인 세션이 남아 있으면 인가 화면 없이 콜백이 즉시 완료되어 초기설정으로 이동하던 동작을 수정했다.
카카오 공식 인가 옵션인 `prompt=login`을 적용해 기존 카카오 세션 유무와 관계없이 계정 인증 화면을 먼저 표시한다.
실행 중 캐시된 공용 라우트에 의존하지 않도록 인증 시작점을 매 요청마다 최신 코드를 실행하는 `page.home` API로 연결했으며, OAuth 콜백의 state 검증과 토큰 교환을 통과한 뒤에만 초기설정으로 이동하는 기존 보안 흐름은 유지했다.

## 원문 요청사항

```text
카카오톡 로그인하기를 눌렀는데, 카카오로 시작하기 누르면 카카오 인증해야지 설정 1로 원래 이렇게 넘어갔는데, 왜 카카오 로그인은 빼고 바로 캐릭터 설정으로 넘어감? 무조건 카카오톡 인증해야지 캐릭터 1로 넘어가야해
```

## 변경 파일 목록

- `src/app/page.home/api.py`: 강제 카카오 계정 인증 인가 요청 API 추가
- `src/portal/season/route/auth/controller.py`: 기존 공용 카카오 인증 주소에도 강제 인증 옵션 적용
- `react-app/src/App.tsx`: 카카오 로그인 버튼을 최신 `page.home` 인증 시작 API로 연결
- `src/assets/jochwon-app/`: 수정된 React 프로덕션 번들 동기화
- `devlog.md`: 작업 요약 행 추가
- `devlog/2026-08-03/019-require-kakao-auth-before-onboarding.md`: 상세 작업 기록

## 남은 리스크

- 카카오톡 인앱 브라우저는 카카오 정책상 `prompt=login`을 지원하지 않는다. 일반 PC·모바일 웹 브라우저에서는 강제 계정 인증 화면이 적용된다.
