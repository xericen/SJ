# 호수공원 세 공간 체험 기록 연결

- 요청: 세종예술의전당, 먹거리부스, 축제부스에서 한 체험이 저장 프로필과 최근 활동기록에 남는지 확인하고 보완한다.
- 원인: 현재 프로필 계산은 체험 상태가 localStorage에 저장된 경우에만 해당 기록을 생성하지만, 맵 진입 경로에서 세 상태를 보장하는 연결이 없었다.
- 변경 파일: `src/assets/jochwon-app/index.html`, `devlog.md`.
- 변경 내용: 맵 활동 API 요청이 성공하면 세 공간별 체험 상태를 프로필 저장 형식에 반영하고 `sejong-experience-profile-updated` 이벤트를 발생시켜 열린 프로필도 즉시 갱신한다.
- 확인: 변경 후 WIZ 프로젝트 빌드 및 정적 문법 검사를 수행한다.
