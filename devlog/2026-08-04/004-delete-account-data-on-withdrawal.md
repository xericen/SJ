# 회원 탈퇴 시 서버 계정·연관 기록 삭제 및 세션 종료 구현

- **ID**: 004
- **날짜**: 2026-08-04
- **유형**: 계정·개인정보 처리 수정

## 작업 요약

브라우저 로컬 상태만 초기화하던 탈퇴 버튼을 인증된 서버 탈퇴 API와 연결했다.
본인 세션을 확인한 뒤 카카오 연결 해제를 시도하고, MySQL 사용자 계정과 AI 행동·체험 기록을 하나의 트랜잭션으로 삭제한 다음 서버 세션을 종료한다.
서버 삭제가 실패하면 브라우저 상태를 지우지 않아 사용자가 오류를 확인하고 다시 시도할 수 있게 했다.
카카오 앱 어드민 키가 설정된 환경에서는 공식 연결 해제 API도 함께 호출하도록 선택 기능을 추가했다.

## 원문 요청사항

```text
현재 탈퇴 안내 문구와 실제 동작이 다릅니다.
정상 탈퇴를 위해 서버 DB·연관 기록 삭제, 세션 종료, 필요 시 카카오 연결 해제 처리가 추가되어야 합니다. 해줘
```

- `src/model/struct/user.py`: 사용자와 AI 행동 기록의 트랜잭션 삭제 로직 추가
- `src/app/page.home/api.py`: 본인 인증 탈퇴 API, 세션 종료, 선택적 카카오 연결 해제 추가
- `react-app/src/services/accountProfile.ts`: 서버 탈퇴 호출 및 WIZ 응답 코드 검증 추가
- `react-app/src/App.tsx`: 서버 탈퇴 성공 후에만 로컬 기록과 화면 상태 초기화
- `config-sample/secret.py`: 선택적 `KAKAO_ADMIN_KEY` 설정 항목 문서화
- `src/assets/jochwon-app/`: 수정된 React 프로덕션 번들 동기화
- `devlog.md`: 작업 요약 행 추가
