# 지도 캐릭터 데스크톱 방향키 이동 구현

- **날짜**: 2026-07-19
- **리뷰 ID**: kjfkfiqkciikcacxpncriwminiqfaurh
- **유형**: 기능 추가 / 메타버스 이동 UX

## 작업 요약

기존 지도 중앙의 이름·위치 핀을 사용자가 만든 캐릭터 외형으로 교체했다.
데스크톱 현장 지도에서 방향키를 누르면 캐릭터가 지도 경계 안에서 이동하고, 이동 방향과 걷기 모션이 즉시 반영되도록 구현했다.
키보드 이동 안내를 지도 상단에 추가하고 입력 요소나 모달 사용 중에는 방향키 이벤트를 가로채지 않도록 제한했다.

## 원문 요청사항

```text
현재 지도에 이름, 위치만 나와있는ㄷ, 낵내가 만든 캐릭터로 메타버스 만드는 거야 즉 내가 만든 캐릭터가 메타버스로 들어가서 움직이며 다른 사람들이랑 얘기할 수 있게, 우선 컴퓨터로 들어갔을 때, 방향키로 움직일 수 있게 해줘
```

## 변경 파일 목록

- `src/app/page.home/view.pug` — 고정 내 위치 핀을 제작 캐릭터 외형으로 교체하고 키보드 이동 안내 추가
- `src/app/page.home/view.scss` — 지도용 캐릭터 축소 렌더링, 이동 전환·방향 전환 및 방향키 안내 스타일 추가
- `devlog.md` — 작업 요약 행 추가
- `devlog/2026-07-19/001-map-character-keyboard-movement.md` — 상세 작업 기록 추가

## 남은 리스크

- 현재 이동 좌표는 브라우저 메모리의 클라이언트 상태이며 서버 저장이나 다른 사용자에게 실시간 동기화되지 않는다.
- 지도 이동 경계는 직사각형 범위로 제한되며 실제 산책로·호수 충돌 판정은 아직 없다.
- 실제 다중 사용자 대화와 위치 동기화는 별도 소켓/백엔드 연동이 필요하다.
