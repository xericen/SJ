# 운영의 가짜 AI 라이프 코스 제거 및 완료 프로젝트 전용 번들 배포

- 원 요청: 실제 완료 프로젝트가 없는데 02 프로젝트 가져오기에 `AI 세종 라이프 코스`가 표시되는 문제를 재확인하고 수정.
- 변경 파일: `src/assets/jochwon-app/index.html`, 최신 정적 번들, `src/app/page.home/view.pug`, `devlog.md`, 본 상세 기록.
- 원인: React 소스는 실제 완료 프로젝트만 필터링하도록 수정됐지만 운영 엔트리가 이전 `index-BBWudHoo.js`를 계속 참조해 과거 샘플 코스를 표시하고 있었다.
- 변경 내용: 최신 완료 프로젝트 전용 빌드 자산을 WIZ 정적 자산에 동기화하고 엔트리를 `index-Cp6SUL22.js`로 교체했다. 캐시 식별자도 갱신했다.
- 확인: 최신 운영 번들에 `내 완료 프로젝트 없음`과 완료 프로젝트 필터가 포함되고, 이전 엔트리 참조가 제거된 것을 확인. React 전체 빌드는 직전 작업에서 성공.
- 남은 리스크: 브라우저가 이전 iframe 문서를 이미 열고 있으면 새로고침 1회가 필요할 수 있다.
