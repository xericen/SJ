# 세종호수공원 포탈 편집 제거 및 공용 좌표 고정

- **ID**: 024
- **날짜**: 2026-08-05
- **유형**: 설정 변경

## 작업 요약

세종호수공원에서는 포탈 위치 편집 버튼이 표시되지 않도록 변경했다. 현재 공용 DB에 저장된 포탈 5개의 좌표를 유지하고, 클라이언트 우회 요청과 별도 Node 서버 요청에서도 호수공원 좌표 변경을 거부하도록 잠갔다.

## 원문 요청사항

```text
세종 호수 공원에 있는 포탈은 현재 위치가 다 마음에 들어서 위치 변경하는 버튼 없애줘, 그리고 그 위치 다른 사용자가 가입하고 들어갔을 때, 위치 동일하게 보이게 해줘.
```

## 변경 파일 목록

- `react-app/src/pages/GamePage.tsx`: 세종호수공원에서 공용 포탈 편집 버튼 미표시
- `src/app/page.home/api.py`: 세종호수공원 포탈 좌표 변경 요청 서버 차단
- `react-app/server/src/socket/registerSocketHandlers.ts`: Node 실시간 서버에서도 고정 맵 변경 차단
- `react-app/index.html`, `src/app/page.home/view.pug`: 운영 빌드 ID v36 갱신
- `src/assets/jochwon-app/`: 최신 React 운영 빌드 반영
