# 중앙광장 PROJECT→AI→VISIT 순환 구조

- 원 요청: 여행 일정 저장 결과를 내 프로필 추천 코스에 넣고 01 프로젝트, 02 AI 일정 확정, 03 일정 및 방문 전광판을 역할에 맞게 분리하며 방문 인증을 다시 프로필에 반영.
- 변경 파일: `src/app/page.home/view.pug`, `src/assets/jochwon-app/index.html`, 최신 정적 번들, `devlog.md`, 본 상세 기록. React 원본은 `/opt/app/SJ/react-app`의 중앙광장 UI·프로필·분석·하네스 파일.
- 변경 내용: 01 데이터 준비, 02 AI 코스 분석·편집·확정, 03 QR·지도·방문 인증으로 화면을 분리했다. 확정 일정은 내 프로필 추천 코스에 표시되고 방문 인증은 활동 기록과 다음 분석에 반영된다.
- 확인: 회귀 테스트 5건 통과, React TypeScript/Vite/서버 및 성능 검증 성공, WIZ `main` 빌드 성공, 운영 반영 확인.
- 남은 리스크: QR은 현재 방문 안내용이며 외부 시설의 실제 검증 QR 시스템과는 연동되지 않는다.
