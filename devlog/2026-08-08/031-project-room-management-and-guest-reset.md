# 프로젝트실 신청 승인·거절·삭제 및 체험용 세션 정리 연결

- 원 요청: 프로젝트 상세에서 신청자 확인·수락·거절, 내 프로젝트 삭제, 자기 프로젝트 신청 차단, 체험용 이탈 시 프로젝트 데이터 정리.
- 변경 파일: `react-app/src/components/ProjectRoomInteractions.tsx`.
- 변경 내용: 프로젝트 소유자 전용 신청자 프로필 관리와 승인/거절, 삭제 버튼을 추가하고, 둘러보기·상세 신청 조건을 소유자/참여자 기준으로 제한했습니다. 비로그인 체험 사용자가 공동캠퍼스로 나가면 프로젝트실 메모리 상태를 초기화합니다.
- 확인: React 빌드 및 WIZ 운영 배포 후 운영 번들 정적 응답 확인.
