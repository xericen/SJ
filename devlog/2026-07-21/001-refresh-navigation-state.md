## 사용자 원 요청

> 새로고침하면 https://sj.wizide.com/home 화면으로 자꾸 들어가는데, 로그인 페이지에서 새로고침하면 로그인 페이지가 유지되고 다른 페이지에서 새로고침하면 해당 페이지가 유지되게 해 달라는 요청.

## 작업 요약

홈 컴포넌트 내부 화면 상태를 브라우저 URL 쿼리에 동기화하고 초기 진입 시 URL에서 다시 복원하도록 변경했습니다. 이제 로그인·회원가입 단계, 동네 목록, 멀티버스 기능, 로그인한 사용자의 생활권 방, 동아리와 상세 탭, 커뮤니티 패널 상태가 새로고침 후에도 유지됩니다.

브라우저 뒤로가기·앞으로가기에도 같은 복원 로직이 동작하도록 `popstate` 처리를 추가했습니다. 인증이 필요한 생활권·동아리·이웃 화면에서 세션이 만료된 경우에는 안전하게 로그인 화면을 표시합니다. URL에는 이메일·비밀번호·채팅 내용 등 민감하거나 입력 중인 데이터는 기록하지 않습니다.

## 남은 리스크

- 자동화 브라우저가 없는 환경이라 실제 브라우저 새로고침과 뒤로가기 조작은 정적·HTTP 수준으로 확인했습니다.
