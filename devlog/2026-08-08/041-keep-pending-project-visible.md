# 생성 중 프로젝트 목록 유지

- 원본 요청: 프로젝트가 생성된 직후 프로젝트실 목록에서 사라지는 원인을 찾고 수정해 달라는 요청.
- 변경 파일: `react-app/src/services/projectRoomProjects.ts`
- 변경 내용: 공유 저장 요청이 실패했을 때도 pending 프로젝트를 즉시 제거하지 않도록 수정했다. 실시간 재조회가 이전 서버 목록을 받아도 저장 중인 프로젝트를 계속 병합해 프로젝트실 안에서 사라지지 않게 한다.
- 검증: `npm run build` 성공 예정 후 WIZ 운영 빌드 반영.
