# 비로그인 월드 진입 문구를 맵 구경하기로 변경

## 사용자 원문 요청

> 로그인을 하지 않은 상태로, 16개의 실제 월드를 3D로 보고싶으면 체험하기 누르면 캐릭터 없이 맵만 볼 수 있게 해줘 -> 로그인 안한 상태면 맵 입장하기가 아니고, 맵 구경하기로 바꿔야지

## 변경 내용

- 비로그인 상태의 월드 모달 기본 버튼을 `맵 구경하기`로 변경했다.
- 비로그인 월드 카드와 전용 맵 화면의 안내 문구도 `구경하기` 표현으로 통일했다.
- 로그인 상태에서는 기존 `월드명 입장하기` 문구를 유지했다.
