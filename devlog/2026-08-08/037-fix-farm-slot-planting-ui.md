# 마이홈 위치별 꽃 식재 UI

- 원본 요청: 중앙에 표시되는 식물 식재 UI를 없애고, 마이홈 앞 1~5번 위치에 접근했을 때 원하는 꽃을 심거나 설치된 식물을 제거할 수 있게 해 달라는 요청.
- 변경 파일: `react-app/src/components/PersonalFarmProgressExperience.tsx`
- 변경 내용: 중앙 화단 앵커 기반 식재 UI와 별도 근접 제거 카드를 제거했다. 1~5번 화단 슬롯 근접 이벤트를 기준으로 슬롯 번호, 수집 꽃 선택, `E · 꽃 심기`, 설치된 식물의 `식물 제거` 버튼을 표시하고 기존 슬롯 API로 저장한다.
- 검증: `npm run build` 성공 및 성능 예산 검사 통과.
