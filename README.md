# 세종한바퀴

세종한바퀴는 아바타로 세종의 자연·문화·축제·먹거리·캠퍼스를 탐험하고, 탐험 과정에서 쌓인 취향과 활동 기록을 실제 세종 방문 코스로 연결하는 3D 소셜 월드입니다.

가상 공간을 둘러보는 데서 끝나지 않고 사용자가 세종에 흥미를 느끼고 실제로 방문하도록 돕는 것이 프로젝트의 목표입니다.

> 배포 사이트의 게스트용 공간 미리보기에서 총 17개 월드와 실제 인게임 GLB 기반 3D 미리보기를 확인할 수 있습니다.

## 배포 사이트

https://sj.wizide.com/home

로컬 환경에서는 MySQL 서버 IP에 접근할 수 없어 데이터베이스 연동 기능을 정상적으로 이용하기 어렵습니다. 프로젝트 체험은 위 배포 사이트로 접속해 주세요.

## 전체 사용자 여정

`세종 탐험 → 취향 발견 → 활동 기록 → 사람과 프로젝트 연결 → AI 방문 코스 생성 → 실제 세종 방문`

사용자는 세종호수공원에서 탐험을 시작해 베어트리파크, 공동캠퍼스, 정부청사로 이동합니다. 공연 저장, 먹거리 관심, 축제 체험, 꽃 채집, 동아리와 프로젝트 활동이 프로필 데이터로 이어지고 중앙광장 AI가 이를 방문 코스에 반영합니다.

## 로그인 사용자와 게스트

서비스는 카카오 로그인 사용자와 게스트 체험으로 구분됩니다.

| 구분 | 카카오 로그인 사용자 | 게스트 사용자 |
|---|---|---|
| 이용 조건 | 카카오 테스트 로그인 대상자만 가능 | 게스트로 체험 가능 |
| 3D 월드 탐험 | 가능 | 가능 |
| 친구 추가 | 가능 | 불가 |
| 1:1 채팅 | 가능 | 불가 |
| 사용자 정보 | MySQL에 저장 | 세션 캐시에 임시 저장 |
| 활동 기록 | MySQL에 저장 | 세션 캐시에 임시 저장 |
| 동아리 생성 | 재접속 후에도 기록 유지 | 세션 동안만 유지 |
| 기억나무 기록 공개 | 탐험 기록 공개 시 가능 | 불가 |
| 중앙광장 AI 분석 | 데이터베이스에 저장된 프로필과 활동 정보 사용 | 더미 데이터 사용 |
| 재접속 후 기록 | 저장된 기록 유지 | 유지되지 않음 |

게스트의 친구 추가와 1:1 채팅은 성인과 미성년자 사이의 무분별한 채팅을 방지하기 위해 제한했습니다.

## 주요 월드

| 권역 | 연결 공간 | 핵심 체험 |
|---|---|---|
| 세종호수공원 | 세종예술의전당, 먹거리 부스, 축제 부스, 베어트리파크 가는 길, 공동캠퍼스 가는 길 | 세종의 문화·축제·먹거리를 경험하고 취향 발견 |
| 베어트리파크 | 곰 체험소, 수목원 | 곰 먹이 주기, 꽃 채집, 기억나무 기록 |
| 공동캠퍼스 | 모집센터, 동아리 거리제, 학생회관, 프로젝트실, 정부청사 가는 길 | 모집·동아리·프로젝트를 통한 사용자 연결 |
| 정부청사 | 중앙광장, 전망대, 세종 스마트시티 국가시범도시 | 저장된 경험 분석과 실제 방문 코스 생성 |

## 월드별 주요 기능

### 세종호수공원

서비스가 처음 시작되는 중심 월드입니다. NPC 충녕이가 이용 방법을 안내합니다.

- 세종예술의전당, 먹거리 부스, 축제 부스로 이동할 수 있습니다.
- 베어트리파크와 공동캠퍼스로 가는 길이 연결되어 있습니다.
- 충녕이 NPC를 통해 월드 이용 방법을 안내받습니다.

#### 세종예술의전당

- 세종에서 열리는 뮤지컬과 공연을 소개합니다.
- 실제 공연 티저를 확인할 수 있습니다.
- 관심 있는 공연을 저장해 프로필 기록으로 남길 수 있습니다.

#### 먹거리 부스

- 세종에 실제로 있는 카페와 음식점을 소개합니다.
- 지도에서 해당 장소의 위치를 확인할 수 있습니다.

#### 축제 부스

- 세종의 축제 정보를 안내합니다.
- 축제별 세부 정보를 확인할 수 있습니다.
- 축제 영상에서 티저 영상을 볼 수 있습니다.

### 베어트리파크

곰 체험소와 수목원으로 연결되는 자연 탐험 월드입니다.

#### 곰 체험소

- 먹이 5개를 찾아 곰에게 줄 수 있습니다.
- 곰이 먹이를 먹으면 GLB 파일에 저장된 춤 중 하나를 무작위로 춥니다.
- 먹이를 다섯 번 주면 마이홈에 곰 동상이 세워집니다.

#### 수목원

- 꽃 5종을 채집할 수 있습니다.
- 채집한 꽃은 마이홈의 원하는 다섯 자리에 심을 수 있으며 최대 5개까지 배치할 수 있습니다.
- 식물 5종을 해금하면 기억나무에서 자신의 감정을 담은 편지를 작성할 수 있습니다.
- 기억나무 기록은 탐험 기록을 공개해야 나타납니다.
- 탐험 기록 공개는 로그인 사용자만 가능하며 게스트는 기록을 남길 수 없습니다.

### 공동캠퍼스

모집센터, 동아리 거리제, 학생회관, 프로젝트실과 정부청사 가는 길을 연결하는 교류 월드입니다.

#### 모집센터

- 모집글을 작성하고 조회할 수 있습니다.
- 모집글에 참여할 수 있습니다.
- 현재 표시되는 일부 모집글은 화면을 풍성하게 구성하기 위한 더미 데이터입니다.

#### 동아리 거리제

- 관심 있는 동아리를 생성할 수 있습니다.
- 다른 사용자가 만든 동아리에 참여할 수 있습니다.
- 게스트가 만든 동아리는 현재 세션에서만 유지됩니다.
- 로그인 사용자가 만든 동아리는 데이터베이스에 저장됩니다.

#### 학생회관

- 사용자들이 어느 공간에서 활동 중인지 보여 주는 장소입니다.
- 현재 위치 정보에는 더미 데이터가 사용됩니다.

#### 프로젝트실

- 프로젝트를 만들고 실제 방문할 장소와 코스를 함께 논의할 수 있습니다.
- 자신이 만들었거나 참여 중인 동아리를 불러와 프로젝트를 생성할 수 있습니다.
- 동아리 거리제에서 만들어진 모임을 프로젝트실의 여행 코스 협업으로 연결합니다.

### 정부청사

프로필 완성도가 50% 이상이면 정부청사로 가는 길이 해금됩니다.

#### 전망대

- 높은 건물에서 세종을 내려다보는 느낌으로 세종의 풍경을 감상할 수 있습니다.

#### 세종 스마트시티 국가시범도시

- 세종이 추진하는 스마트시티의 종류를 전시 형태로 보여 줍니다.
- AI, 자율주행, 스마트 에너지 관련 전시 공간으로 구성되어 있습니다.

#### 중앙광장

- 프로젝트실에서 만든 프로젝트를 가져올 수 있습니다.
- AI 여행 일정 확정센터에서 프로젝트 코스에 적합한 세종 장소를 추가해 방문 코스를 완성합니다.
- 완성된 일정을 확인하고 저장할 수 있습니다.
- 로그인 사용자는 데이터베이스에 저장된 프로필과 활동 정보를 분석에 사용합니다.
- 게스트 사용자는 더미 데이터를 사용합니다.

## 중앙광장 AI 프롬프트

중앙광장 AI에는 다음 원칙이 적용되어 있습니다.

| 원칙 | 적용 내용 |
|---|---|
| 추천 범위 | 입력으로 제공된 세종 후보 장소 안에서만 추천 |
| 정보 정확성 | 존재하지 않거나 확인되지 않은 장소·주소·운영 정보를 생성하지 않음 |
| 분석 정보 | 사용자가 직접 제공하거나 서비스에 저장된 취향과 활동 기록만 사용 |
| 조건 반영 | 이동 수단, 이용 시간, 예산, 동행 조건이 있으면 코스에 반영 |
| 체험 연결 | 축제·식물·공동캠퍼스 체험이 추천에 반영된 이유를 설명 |
| 지역 연결 | 후보에 포함된 실제 지역 카페·음식점·공방·상점을 우선 고려 |
| 결과 형식 | 최대 4곳의 방문 순서와 추천 근거를 간결한 한국어로 생성 |

AI가 임의로 관광지를 만들어 내는 방식이 아니라, 제공된 후보 장소와 실제 사용자 기록을 바탕으로 세종 방문 코스를 구성하도록 제한했습니다.

## AX 적용 요소

세종한바퀴의 AX는 AI 기능 하나를 별도로 제공하는 것이 아니라 탐험 전체 과정에 AI가 자연스럽게 이어지도록 구성한 점에 있습니다.

| 단계 | AX 적용 방식 |
|---|---|
| 안내 | 충녕이 NPC가 첫 월드와 이동 경로 안내 |
| 취향 발견 | 공연 저장, 먹거리 관심, 축제 체험을 사용자 취향으로 기록 |
| 자연 탐험 | 꽃 채집과 식물 기록을 프로필 데이터로 연결 |
| 사람 연결 | 동아리와 프로젝트 활동을 방문 계획으로 연결 |
| 코스 생성 | 중앙광장 AI가 프로필과 활동 기록을 분석해 세종 방문 코스 생성 |

3D 월드에서의 선택을 실제 방문 계획으로 전환해 사용자가 세종에 관심을 갖고 직접 방문하도록 돕습니다.

## 배포 사이트에서 확인 가능한 내용

- 세종호수공원, 베어트리파크, 공동캠퍼스, 정부청사를 포함한 총 17개 월드 목록
- 각 월드의 주요 체험 안내
- 실제 인게임 GLB 파일을 사용한 3D 월드 미리보기
- 마우스 드래그를 이용한 모델 회전
- 마우스 휠을 이용한 모델 확대

## 이용 시 참고사항

- 카카오 로그인은 테스트 로그인 대상자로 등록된 사용자만 가능합니다.
- 로컬 환경에서는 MySQL 서버 IP 접근 제한으로 데이터베이스 연동 기능을 이용하기 어렵습니다.
- 전체 기능 체험은 배포 사이트 이용을 권장합니다.
- 모집센터와 학생회관의 일부 정보는 더미 데이터입니다.
- 게스트 기록은 세션 캐시에 저장되므로 재접속 시 유지되지 않습니다.
