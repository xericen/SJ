# 프로젝트 협업 자동 저장·새로고침 경합 방지 및 전원 합의 완료

- **ID**: 102
- **날짜**: 2026-08-09
- **유형**: 협업 데이터·완료 흐름 수정

## 작업 요약

프로젝트 협업 테이블의 장소·테마·먹거리·대화·코스 변경을 발생 순서대로 서버에 자동 저장하도록 저장 대기열을 추가했다. 저장 완료 전 자동 조회나 수동 새로고침이 이전 서버 초안을 덮어쓰지 않도록 조회를 대기시켰으며, 서버에서는 아이디어와 대화를 ID 기준으로 누적 병합한다. 최종 합의는 팀장이 요청하고 모든 참가자가 각자 동의한 뒤 서버 검증을 통과해야만 프로젝트가 완료되도록 기존 합의 API를 화면에 연결했다.

## 원문 요청사항

```text
프로젝트 실에 협업 테이블 할때 새로고침을 누르면 전에 했던걸로 롤백되는게 아니라 내용을 추가 할때 마다 저장되는 구조로 바꿔줘 예를 들어서 내가 장소 추가 누르고 세종호수공원을 선택을 해서 장소 추가를 하면 세종 호수공원이 추가가 되잖아 그다음에 다른 사람은 내가 추가한걸 바로 못보는 문제가 있어서 새로고침을 넣어서 새로고침하면 내가 추가한 내용을 같이 프로젝트 한 사람이 볼 수 있도록 만든 버튼이였어. 그리고 최종합의 검토 버튼 누르면  코스 완성하기 나오는데 이때 완성 누르면 바로 완성 되는게 아니라 협업테이블 같이 하는 사람들이 같이 동의 해야 완성하는걸로 해줘
```

## 원인

- 변경 저장과 2초 자동 조회가 서로 독립적으로 실행되어 저장 응답 전 조회가 이전 초안을 가져오면 화면이 롤백될 수 있었다.
- 저장 응답도 현재보다 오래된 초안을 다시 적용할 수 있어 연속 추가 중 일시적인 데이터 후퇴가 가능했다.
- 서버는 아이디어만 병합하고 대화는 마지막 요청으로 덮어써 동시 추가 보존이 불완전했다.
- 서버에 전원 합의 API가 있었지만 화면의 `코스 완성` 버튼은 이를 사용하지 않고 즉시 로컬 완료 처리했다.
