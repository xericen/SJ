# 프로젝트 아이디어 실시간 동기화와 완료·정부청사 이동 분리

- **ID**: 042
- **날짜**: 2026-08-09
- **유형**: 버그 수정

## 작업 요약

프로젝트 협업 테이블 입장 시 프로젝트 전용 소켓 방 재가입을 보장하고, 아이디어 초안을 WIZ 공용 협업 저장소와 동기화했다. 코스 완성과 정부청사 이동을 분리하고 완료 프로젝트 상태를 중앙광장 01 화면의 데이터 원본에 저장하도록 변경했다.

## 원문 요청사항

```text
프로젝트실에서 아이디어보드 실시간으로 다른 사람이 추가한 거 볼 수 있게해줘, 테마왐 먹거리도 동일하게 아이디어 추가하는 거 실시간으로 볼 수 있게해줘, 최종합의 검토 누르면 코스 코스완성- 정부청사 이동 이렇게 말고 코스완성만 떠서 프로젝트 완성되게 해주고,  정부청사로 넘어가시겠습니까? 창 떠서 간다 안간다 선택할 수 있게 해줘. 그리고 완성하면 정부청사 중앙광장 01 프로젝트 완료에 뜨게 해줘. 다 원인 찾고 해결해줘!
```

## 변경 파일 목록

- `react-app/src/components/ProjectRoomInteractions.tsx`: 프로젝트 방 재가입, 공용 초안 동기화, 완료 상태 저장, 정부청사 이동 선택 창
- `src/app/page.home/api.py`: 동시 추가 아이디어의 ID 병합 및 투표 수 보존
- `react-app/scripts/reviewOpsRegression.test.ts`: 실시간·완료·중앙광장 연결 회귀 검사
- `src/app/page.home/view.pug`: 운영 iframe 빌드 식별자 갱신
- `src/assets/jochwon-app/`: 프로덕션 번들 갱신
