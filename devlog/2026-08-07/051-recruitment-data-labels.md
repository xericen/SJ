# 모집 목록 기본 데이터의 프로젝트 명칭을 모집으로 통일

- 사용자 요청: 모집글 참가하기 화면에 남아 있는 `수목원 사진 기록 프로젝트` 등 모든 프로젝트 명칭을 모집 명칭으로 바꾼다.
- 변경 파일: `react-app/src/components/RecruitmentCenterDesk.tsx`, 배포 정적 자산 `src/assets/jochwon-app/`.
- 변경 내용: 기본 추천 데이터와 모집글 카드·상세·프로필 전달 확인 화면의 표시 제목에서 `프로젝트`를 `모집`으로 변환하고, 참가 버튼 문구도 모집 참가로 통일했다. 내부 프로젝트 데이터 구조는 기존 신청 호환성을 위해 유지했다.
- 확인: React/Vite 빌드 및 성능 검사 통과, `git diff --check` 통과, WIZ `main` 프로젝트 빌드 성공.
