# 캐릭터 설정 2단계 저장 버튼 겹침 수정

## 사용자 요청

> 캐릭터 설정 2단계 비율이 커서 아래 신발 옵션과 캐릭터 저장하기가 겹치며 여성형 2·남성형 2도 마지막 옵션이 저장 버튼과 겹치는 문제를 수정해 주세요.

## 원인

- 1440×900 화면에서 확장형 캐릭터는 모양 4개와 색상 6개 옵션 행이 함께 표시되지만 각 행의 최소 높이가 커 하단 저장 버튼 행을 침범했습니다.

## 변경 내용

- 데스크톱 높이 950px 이하에서 캐릭터 설정 2단계의 제목, 미리보기, 모델 선택 카드와 옵션 행을 균형 있게 축소했습니다.
- 남성형 2·여성형 2의 모양·색상 옵션 행 높이를 50px로 줄이고 버튼과 아이콘 크기를 함께 조정했습니다.
- 하단에 54px 저장 버튼 전용 그리드 행을 확보해 신발·마지막 옵션과 겹치지 않도록 했습니다.
