# 멀티버스 맵 중심 입장 화면 조정

- **ID**: 009
- **날짜**: 2026-07-19
- **유형**: UX 개선

## 작업 요약

동네 입장 화면에서 멀티버스 맵이 주 콘텐츠로 보이도록 데스크톱 지도 너비와 높이를 확대했습니다.
지도 위 플레이어 캐릭터와 주변 이웃 마커는 지도 스케일에 맞게 축소하고, 상단 정보 영역과 우측 이웃 패널의 점유 공간도 줄였습니다.

## 원문 요청사항

```text
입장했을 때 우리의 주된 포인트가 멀티버스 맵이기 때문에, 맵이 크게 보여야해, 그리고 사람이 너무 크게 보임, 이 부분 수정해줘,
```

## 변경 파일 목록

- `src/app/page.home/view.scss`
  - 방 화면 최대 너비를 1240px에서 1380px로 확대
  - 맵 높이를 화면 높이에 반응하는 620~780px 범위로 확대
  - 우측 이웃 패널 너비와 상단 여백 축소
  - 플레이어 캐릭터 배율을 0.48에서 0.32로 축소
  - 맵 위 주변 이웃 마커를 38px에서 29px로 축소
- `devlog.md`
- `devlog/2026-07-19/009-multiverse-map-focus-scale.md`

## 확인 결과

- WIZ 일반 빌드 성공
- 생성 번들에서 확대된 맵 레이아웃과 축소된 캐릭터 스타일 반영 확인
- 1440px 화면 기준 맵 예상 크기 약 956×520px → 1138×690px
- 캐릭터 예상 표시 크기 약 58×120px → 38×80px
- 800px 이하 단일 열 및 모바일 전용 맵 높이 규칙 유지 확인

## 남은 참고사항

- 실제 로그인 계정으로 여러 브라우저에서 입장 화면을 육안 비교하는 검수는 별도로 필요합니다.
