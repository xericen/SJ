# 카카오 로그아웃 후 재로그인 화면 강제 표시

## 사용자 요청

카카오 로그인 후 로그아웃하고 다시 카카오 로그인을 누르면 처음부터 카카오 로그인을 진행하도록 수정한다. 기존처럼 바로 세종호수공원으로 들어가는 문제를 해결한다.

## 변경 파일

- `src/app/page.home/api.py`
- `react-app/src/App.tsx`
- `devlog.md`
- `devlog/2026-08-09/094-force-kakao-reauthentication.md`

## 변경 내용

로그아웃 시 브라우저에 재인증 필요 상태를 기록하고, 다음 카카오 OAuth 시작 요청에만 `reauth=1`과 `prompt=login`을 적용했다. 이때 남은 앱 세션도 먼저 초기화해 카카오 제공자 브라우저 세션을 자동 재사용하지 않고 카카오 로그인 화면을 다시 표시한다.

## 검증

카카오 로그아웃·재로그인 회귀 테스트 2건, Python 문법 검사, React 프로덕션 빌드·성능 검사, WIZ 빌드 통과.

빌드에는 기존 SUIT 폰트 경로의 런타임 해석 경고가 남아 있으나 이번 로그인 수정과 무관하다.
