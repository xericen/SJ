# 충녕이·사용자 이름표 크기 통일 및 예술의전당 이동 구간 보정

## 사용자 원문 요청

> 충녕이 이름표 크기랑 내 이름표 크기랑 동일하게 바꿔주고, 현재 위치에서 세종예술의 전당가는 위치에 가고 있는데 이 구간에서 자꾸 걸려 이 부분 해결해줘

## 변경 파일

- `src/assets/jochwon-app/assets/GamePage-vnOFqgno.js`
  - 충녕이 이름표에서 별도 안내 NPC 배지를 제거해 사용자 이름표와 동일한 단일 이름 레이아웃과 크기를 사용하도록 변경했습니다.
  - 현재 시작 위치에서 세종예술의전당 포털로 이어지는 구간에 지면 샘플 fallback을 추가해 메시 틈이나 비정상 경사 판정에서 이동이 멈추지 않도록 했습니다.
- `src/assets/jochwon-app/index.html`
  - 변경 번들 반영을 위한 빌드 ID를 갱신했습니다.
- `src/app/page.home/view.pug`
  - iframe 빌드 쿼리를 새 빌드 ID와 일치시켰습니다.

## 검증 결과

- 변경 번들의 JavaScript 구문 검사를 통과했습니다.
- 충녕이 단일 이름표와 예술의전당 이동 구간 fallback 범위를 정적 확인했습니다.
- WIZ 프로젝트 일반 빌드를 통과했습니다.
