# 중앙광장 렌더링 부하 완화

- 원 요청: 중앙광장맵에서 렉이 너무 많이 걸리는데 해결.
- 변경 파일: `react-app/src/game/renderers/VillageMapRenderer.ts`
- 변경 내용: 중앙광장에만 안티앨리어싱을 끄고, 렌더링 목표를 30fps로 낮췄으며, 픽셀 비율을 0.75~0.95 범위에서 적응 조정하도록 변경했다. GLB 지오메트리는 중앙광장에 한해 보수적으로 단순화해 AI 홀로그램·웹 패널과의 GPU 경쟁을 줄였다. 다른 맵 설정은 변경하지 않았다.
- 확인: WIZ `main` 빌드 성공, React TypeScript·Vite 빌드 성공, 성능 예산 검증 성공.
- 남은 리스크: 실제 GPU별 FPS와 발열은 운영 브라우저에서 추가 측정이 필요하며, 일부 미세한 모델 외곽선이 이전보다 단순하게 보일 수 있다.
